# 作品名称
温度联动呼吸灯
## 1. 功能概述
本作品以 STM32F103C8T6 为主控，通过 NTC 热敏电阻采集环境温度，并利用 PWM 控制 RGB LED 实现随温度变化的呼吸灯光效果。

## 2. 硬件清单
| 名称 | 型号 | 数量 | 用途 |
|------|------|------|------|
| STM32 开发板 | STM32F103C8T6 | 1 | 主控 |
| NTC热敏电阻 | 10k | 1 | 温度传感器 |
| RGB LED | 共阳RGB | 1 | 执行器、呼吸灯显示 |

## 4. 实现思路
- 系统框图（文字或图片）
  NTC → ADC 采样 → 阻值 / 温度换算 → 逻辑判断 → TIM3 PWM → RGB LED
（同时：温度数据 → USART → 电脑串口助手）
- 主循环 / 状态机怎么组织
  1. DMA 循环读取 ADC 采样值
  2. 根据分压公式算出 NTC 电阻
  3. 通过 NTC 的 B 值公式计算温度
  4. 将温度映射到 PWM 占空比
  5. 修改 TIM3 比较值，完成呼吸 / 亮度变化
  6. 串口循环打印温度
- 通信协议（如串口指令/返回格式；没用到可删）
  使用 USART2，波特率 115200，8 数据位、无校验、1 停止位；
  串口返回格式：
  Temp:xx.xx C | Rntc:xxxx Ohm

| 问题 | 现象 | 原因 | 解决 |
| 串口助手无输出 | 发送数据但电脑接收不到 | 开发板与LED共地时断路 | 先排除了代码和芯片配置的问题，然后让开发板烧录之前成功的呼吸灯，发现还是不亮，后面惊鸿一瞥发现开发板的GND连到面包板另一半了 |
| 串口打印速度过快 | 打印滚动速度过快 | HAL_Delay（）延时不够长 | 增大HAL_Delay函数的数值 |
